# Lesson 272 - Ma hinh ung dung (Application Cryptography)

## Lesson Content

**Topic:** Hash vs encryption, HMAC, and AEAD - practical cryptography for developers

**Key Concepts:**
- **Hash functions** (SHA-256, SHA-3, Argon2): one-way, deterministic, no key needed
- **Encryption** (AES-GCM, ChaCha20-Poly1305): reversible with key, provides confidentiality
- **HMAC**: keyed hash for message authentication (integrity + authenticity)
- **AEAD** (Authenticated Encryption with Associated Data): encryption + integrity in one operation

**Main Topics:**
- When to use hash vs encryption vs HMAC vs AEAD
- OWASP cipher/hashing recommendations
- Nonce/IV handling and why nonce reuse is dangerous (RFC 5116)
- Timing-safe comparison for secrets
- Real-world case studies: Sony PlayStation hack, Let's Encrypt nonce reuse incident
