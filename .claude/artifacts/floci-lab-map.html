01

Emulator AWS cục bộ

Tầng mô phỏng gần nhất với floci: chạy dịch vụ AWS trên máy của bạn thay vì cloud thật — từ emulator toàn diện, đến mock trong test, đến emulator chính thức của riêng AWS.

floci-io/floci MIT Java / Quarkus 20.2k ⭐ · 2.1k fork Verified · 3-0 & 2-0
Mô phỏng gì69 dịch vụ AWS qua HTTP router tại localhost:4566 — dùng cho development, testing và CI.
Định vịDrop-in replacement cho LocalStack Community sau khi bản community bị sunset tháng 3/2026: port, credentials, SDK & CLI endpoint tương thích ngược, kèm auto-translate biến môi trường (LOCALSTACK_HOST→FLOCI_HOSTNAME, PERSISTENCE=1→FLOCI_STORAGE_MODE=persistent).
Vì sao solution architect nên biết

Đây là ví dụ điển hình về "ai đang thay LocalStack Community sau 3/2026" — bối cảnh bạn cần nắm khi thiết kế workflow dev/test cho ứng dụng AWS của đội. Chi phí bằng 0, chạy được trong CI.

  • Lưu ý độ tin cậy: cụm từ "đóng băng bảo mật" của LocalStack Community chỉ xuất phát từ bảng so sánh của chính floci, không phải tuyên bố độc lập từ LocalStack.
localstack/localstack 65.1k ⭐ ARCHIVED 23/03/2026 Caveat
Mô phỏng gìCloud service emulator chạy trong một Docker container trên laptop hoặc CI — emul rộng các AWS service (Lambda, S3, DynamoDB, Kinesis, SQS, SNS, API Gateway, CloudFormation, CloudWatch, ACM, Config). Công cụ học/test CDK & Terraform.
Diễn biếnRepo chính thức đã bị owner archive ngày 23/03/2026 (read-only) — phát triển gộp về "một image thống nhất", bug/feature chuyển sang Discussions & Slack.
Vì sao solution architect nên biết

LocalStack là "ông tổ" của họ này — hiểu nó là hiểu chuẩn emulation AWS mà floci và mọi alternative đang so sánh. Nhưng lưu ý thời điểm: nay cần auth token, và AWS Config chỉ bị mocked (CRUD giả, không ghi nhận thay đổi cấu hình thực).

getmoto/moto Python Mock in-test Verified · 3-0 & 2-0
Mô phỏng gìThư viện Python mock AWS ngay trong test bằng cách chặn lệnh gọi boto3 (qua botocore event layer), giữ state in-memory (vd trạng thái bucket/key của S3) và tự reset khi mock kết thúc.
Khác floci ở điểm nàoNhẹ hơn, chạy trong process test — không cần container. Nhưng chỉ giỏi cho test, không phải full dev/CI sandbox.
Vì sao nên biết

Tầng "mock nhẹ" cho unit/integration test trong Python — công cụ tối giản khi bạn không cần cả một AWS stack.

DynamoDB Local Chính thức của AWS Verified · 3-0
Mô phỏng gìEmulator chính thức của AWS cho DynamoDB — build/test ứng dụng trên máy cục bộ như một database tự chứa, không cần truy cập DynamoDB web service thật.
Vì sao nên biết

Pattern "emulator 1-service của chính nhà cung cấp" — nguồn chân lý về mô phỏng khi không muốn phụ thuộc bên thứ ba. Có trên Docker Hub (AWS Verified Publisher).

02

Testcontainers — hạ tầng tạm quanh mỗi test

Cầu nối giữa emulation và test: khai báo dependency bằng code, container tự tạo quanh test rồi bị xóa. Có module LocalStack chính thức cho Java và Go — gắn trực tiếp vào bức tranh local emulation.

testcontainers-java + testcontainers-go · node · .net · python · rust Verified · 3-0 ×4, 2-1
Khái niệm"Lightweight, throwaway instances" của database, message brokers, Selenium browsers — bất cứ thứ gì chạy được trong Docker. Mô hình "test dependencies as code": loại bỏ mocks và cấu hình môi trường phức tạp; Docker là runtime requirement duy nhất (có sắc thái Podman/Testcontainers Cloud).
Hệ sinh thái Gotestcontainers-go áp cùng triết lý cho Go (~80 modules chính thức như Postgres, Redis, Kafka) trong integration/smoke tests.
Vì sao solution architect nên biết

Đây là pattern chuẩn để test cloud/serverless app không cần cloud thật — nền tảng cho cả chiến lược CI của bạn. Được Spring Boot công nhận là canonical (@ServiceConnection, từ 3.1 đến 4.1).

Module LocalStack · Java & Go org.testcontainers:testcontainers-localstack Caveat · cần token
Dùng thế nàoLaunch "a fully functional local AWS cloud stack" thành Docker container trong code, rồi build AWS SDK S3Client trỏ endpoint localstack (getEndpoint/getAccessKey/getRegion). Go: localstack.Run(ctx, …) tự set LOCALSTACK_HOST cho các API nhạy hostname.
⚠️ Caveat vận hành quan trọng

Từ tháng 3/2026, container LocalStack cần LOCALSTACK_AUTH_TOKEN mới khởi động được — ảnh hưởng trực tiếp đến CI pipeline đang dùng pattern này. Đây là nơi floci (miễn phí, không token) trở nên hấp dẫn.

03

Lab thực hành system design

Học thiết kế hệ thống không chỉ bằng đọc — mà bằng môi trường mô phỏng thực thi thật, phòng lab "đấu trường", và khóa học lộ trình có cấu trúc.

Derssa/Torollo MIT · npm "torollo" ~400 ⭐ Verified · 3-0 ×3
Là gì"The Packet Tracer of backend engineering" — playground trực quan, mã nguồn mở, học system design & networking hoàn toàn cục bộ.
Mô phỏng thế nàoKhông phải emulator API giả — là lab thực thi thật: mỗi node trên canvas ánh xạ 1:1 với Docker container thật; vẽ một liên kết là ghi firewall rule thật (iptables trong container); thêm database là khởi động database thật (PostgreSQL/MongoDB/Redis). Có roadmap tự chấm điểm bằng validator thăm dò state thực — "You can't bluff it, and that's the point."
Hiện tạiCatalogue 3 bài tập ~30–40 phút: three-tier app, cache-aside với Redis, workers với Redis job queue.
Vì sao solution architect nên biết

Gần nhất với điều bạn gọi là "mô phỏng lab kiểu floci nhưng cho kiến trúc": vẽ kiến trúc rồi nhìn nó chạy thật, chống "học tủ". Dự án còn rất sớm (ít ⭐, npm release mới 2.5 tuần tại thời điểm fetch) — nhưng hướng đi độc đáo.

donnemartin/system-design-primer 364k ⭐ 57.9k fork Verified · 3-0 & 2-0
Là gìNguồn học + phòng lab luyện thiết kế hệ thống quy mô lớn. Chứa 8 bài phỏng vấn system design đã giải hoàn chỉnh kèm sample discussions, code và diagrams: Pastebin/Bit.ly, Twitter timeline & search, web crawler, Mint.com, social network, key-value store, Amazon sales ranking, scaling to millions of users on AWS.
Vì sao nên biết

Thuộc nhóm repo giáo dục sao nhất GitHub. Vừa ôn phỏng vấn, vừa là "thư viện case study" để nói chuyện thiết kế với đội như một architect.

karanpratapsingh/system-design 45.6k ⭐ tạo 08/2022 Verified · 3-0 ×2
Là gìKhóa học system design mã nguồn mở, lộ trình có cấu trúc: 4 chương concepts (Networking; Databases; Architecture; System Design Basics — circuit breaker, rate limiting, service discovery, SLA/SLO/SLI, OAuth2/OIDC, TLS/mTLS…) + 5 case study (URL Shortener, WhatsApp, Twitter, Netflix, Uber).
Vì sao nên biết

Bổ sung cho primer: đi theo "giáo trình" thay vì "cẩm nang" — phù hợp nếu bạn thích học có lộ trình từng chương.
