## 3. Nếu bundle này được install vào project mới

1. Chạy `node .claude/tools/generate-repo-facts.js` ngay sau khi copy (hoặc dùng `/portable`).
2. Chạy `node .claude/tools/check-references.js` (warn-only) để bắt refs gãy trong bundle.
3. Review: skill nào generic → giữ, skill nào quá đặc thù repo cũ (vd `shopify`, `payment-integration` nếu không dùng) → tắt trong `settings.local.json` hoặc xóa.
4. Hook paths trong `settings.json` dùng `$CLAUDE_PROJECT_DIR` — portable sẵn, không cần sửa.
